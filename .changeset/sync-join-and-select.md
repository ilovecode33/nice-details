Joining a sync room now merges with the local document instead of replacing it, so an empty or partial room can no longer wipe a device that already has objectives. Only a fresh install still holding the untouched sample data adopts the room. Select menus wrapped in a label (quick length, unit, period, sort, accent) now close after choosing an option instead of reopening through the label's activation behavior.
