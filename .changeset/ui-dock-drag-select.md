`DockNavigation` reuses the appearance switcher's `useSegmentPillDrag` engine: a sliding accent pill sits behind the active item, dragging it follows the pointer with the same damping and settles onto the nearest item, and releasing selects that item. Clicking another item still slides the pill there. The active item is marked in both the expanded and collapsed layouts.
