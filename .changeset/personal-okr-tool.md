Add a personal, frontend-only OKR tracker and its shared domain package. The app uses CSS Modules, keeps each component's style and spec beside it, persists through the IndexedDB-backed `@ilovecode33/persistence` library, shows date-based periods with a quick 2-month preset plus a day/percent countdown, ships English, Traditional Chinese, and German UI, and syncs two devices in realtime through a Cloudflare Durable Object WebSocket room. Each device has an editable, persisted name for the connected-device list.
