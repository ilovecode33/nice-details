# @ilovecode33/ui-swift

SwiftUI skeleton counterpart of `@ilovecode33/ui`: a Swift package (not an npm workspace) that
mirrors platform-neutral contracts and consumes tokens generated by `@ilovecode33/ui-tokens`.

## Build

```bash
swift build --package-path packages/ui-swift
```

`Package.swift` targets iOS 17+ / macOS 14+ and exposes a single `UISwift` library target.

## Layout

```text
@ilovecode33/ui-tokens  ──generates──>  Sources/UISwift/Tokens.swift
@ilovecode33/ui-core    ──mirrored by──>  Sources/UISwift/Contracts.swift
                                          Sources/UISwift/Views.swift
```

## What it provides

- `Contracts.swift` — Swift mirrors of the `ui-core` state models and reducers behind a
  `PortableContract` protocol, plus a `portableContracts` registry covering every contract
  (including ones without a view yet).
- `Views.swift` — SwiftUI renderers: `UIToggle`, `UISegmented`, `UIListView` / `UIListRow`,
  `UISheetView`, plus `UIDeformable` and `UIFloatingBar`. All colors and sizes come from generated
  `UITokens`.
- `Tokens.swift` — generated by `@ilovecode33/ui-tokens`; do not edit by hand.

## Regenerating tokens

```bash
cd packages/ui-tokens
bun run generate
cp generated/Tokens.swift ../ui-swift/Sources/UISwift/Tokens.swift
```

## Parity map

| Contract (`ui-core`) | React (`ui`)          | SwiftUI (`ui-swift`)                    |
| -------------------- | --------------------- | --------------------------------------- |
| `ToggleState`        | `Switch`              | `Toggle` (`UIToggle`)                   |
| `SelectionState<T>`  | `Segmented`, `Select` | `Picker` / `Menu` (`UISegmented`)       |
| `DisclosureState`    | `Disclosure`          | `DisclosureGroup`                       |
| `SheetState`         | `Sheet`               | `.sheet` with detents (`UISheetView`)   |
| `FieldState`         | `FormField`           | `Field` with `@FocusState`              |
| `ListState<T>`       | `List`                | `List` (`UIListView`)                   |
| `FeedbackState`      | `Toast`, `Banner`     | overlay with accessibility announcement |
| `MediaState`         | `PhotoViewer`         | `TabView` with page style               |
| `SelectionModeState` | `PhotoGrid` selection | `EditMode` / selection                  |
| `NavigationState`    | `TabBar`              | `TabView`                               |
